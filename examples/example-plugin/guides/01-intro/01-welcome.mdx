## Quick Install

Get up and running in under 2 minutes. Example Plugin requires WordPress 6.0+ and PHP 8.0+.

```bash
# Install via WP-CLI
wp plugin install example-plugin --activate

# Or via Composer
composer require developer/example-plugin
```

<Callout type="info">
  If you're upgrading from v1.x, check the [Migration Guide](/guides/advanced/migration) for breaking changes.
</Callout>

## Basic Configuration

After activation, configure the plugin in your theme's `functions.php` or a custom plugin. The `example_plugin_configure()` function accepts an associative array of settings that are merged with sensible defaults.

```php
// In your theme's functions.php
add_action( 'plugins_loaded', function() {
    example_plugin_configure([
        'api_key'    => 'your-api-key',
        'debug_mode' => WP_DEBUG,
        'cache_ttl'  => HOUR_IN_SECONDS,
    ]);
});
```

<Callout type="tip">
  Store sensitive values like API keys in `wp-config.php` using `define()` rather than hardcoding them in theme files.
</Callout>
