# Core Concepts

example-plugin is built around three ideas:

1. **Functions** — small, pure helpers you can call from anywhere.
2. **Hooks** — action and filter points for extending behavior.
3. **Blocks** — Gutenberg blocks that render plugin output in the editor.

Each section of the reference documentation covers one of these areas.
Start with whichever best matches the change you want to make.
