# Your First Block

example-plugin ships with a sample Gutenberg block you can use to verify
the editor integration works.

<Callout type="tip">
  Block assets are registered automatically on `init` — no extra setup needed.
</Callout>

Open a post in the editor, click the block inserter, and search for
"Example". The block renders a simple greeting using the plugin's
`example_func()` helper.
