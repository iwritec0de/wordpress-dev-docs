A comprehensive example WordPress plugin demonstrating best practices for hooks, settings, REST API, and PHPDoc documentation.

== Description ==

Example Plugin is a fully documented reference implementation designed to showcase WordPress plugin development best practices. It serves as a test fixture for the wordpress-dev-docs CLI tool and as a learning resource for developers building their own plugins.

**Key features:**

* Singleton class architecture with full PHPDoc documentation
* WordPress Settings API integration with filterable defaults
* Custom REST API endpoints (`example-plugin/v1/settings` and `example-plugin/v1/status`)
* Admin UI with localized JavaScript using `wp.hooks` for extensibility
* CSS custom properties (design tokens) for easy theme integration
* Translation-ready with proper text domain usage throughout

**Developer hooks:**

* Filter: `example_plugin_settings` — modify default settings before they are loaded
* Action: `example_plugin_initialized` — fires after the plugin singleton is created
* JS Action: `example_plugin.init` — fires after the admin UI is initialized
* JS Filter: `example_plugin.settings` — modify settings before the admin form renders

== Installation ==

1. Upload the `example-plugin` directory to `/wp-content/plugins/`.
2. Activate the plugin through the **Plugins** screen in WordPress admin.
3. Navigate to **Settings > Example Plugin** to configure the plugin options.
4. Optionally, use the REST API at `/wp-json/example-plugin/v1/settings` to read or update settings programmatically.

= Minimum Requirements =

* WordPress 6.0 or higher
* PHP 8.0 or higher

== Frequently Asked Questions ==

= How do I change the default settings? =

Use the `example_plugin_settings` filter in your theme's `functions.php` or in a custom plugin:

    add_filter( 'example_plugin_settings', function( $defaults ) {
        $defaults['cache_ttl']        = 7200;
        $defaults['enable_feature_b'] = true;
        return $defaults;
    } );

= How do I use the REST API? =

The plugin exposes two endpoints:

**GET** `/wp-json/example-plugin/v1/settings` — retrieve all settings (requires `manage_options` capability).

**POST** `/wp-json/example-plugin/v1/settings` — update settings. Send a JSON body like:

    { "settings": { "cache_ttl": 3600, "log_level": "debug" } }

**GET** `/wp-json/example-plugin/v1/status` — returns plugin version and active status (public, no auth required).

= Does Example Plugin support multisite? =

Yes. Each sub-site stores its own settings independently via `get_option()` / `update_option()`. Network-wide settings are not currently supported but can be added via the `example_plugin_settings` filter.

= Where can I find the developer documentation? =

Full API documentation generated by wordpress-dev-docs is available at https://example.com/docs/example-plugin.
