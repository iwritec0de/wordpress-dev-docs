# Installation

Example Theme is a WordPress block theme that requires WordPress 6.4 or later
and PHP 8.0+.

## From WordPress Admin

1. Go to **Appearance > Themes > Add New**
2. Search for "Example Theme"
3. Click **Install**, then **Activate**

## From ZIP

1. Download the latest release from the [GitHub releases page](https://github.com/example/example-theme/releases)
2. Go to **Appearance > Themes > Add New > Upload Theme**
3. Upload the ZIP file and click **Install Now**
4. Activate the theme

## Verify

After activation, visit your site. You should see the default block theme
layout with the header, content area, and footer template parts rendered.

Check **Appearance > Editor** to access the Site Editor where you can
customize templates and template parts visually.
