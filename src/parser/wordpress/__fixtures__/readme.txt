A lightweight utility plugin that supercharges your WordPress site with powerful SEO and performance tools.

== Description ==

**My Awesome Plugin** makes your WordPress site faster and easier to manage.

Key features include:

* Automatic image optimization
* Built-in SEO tools
* Performance caching layer
* Developer-friendly hooks and filters

This plugin is built with modern PHP 8 practices and follows WordPress coding standards throughout.

== Installation ==

1. Upload the `my-awesome-plugin` folder to `/wp-content/plugins/`
2. Activate the plugin through the **Plugins** menu in WordPress
3. Navigate to **Settings > My Awesome Plugin** to configure options
4. That's it — your site is now optimized!

== Frequently Asked Questions ==

= Does this plugin work with my theme? =

Yes! My Awesome Plugin is fully compatible with any well-coded WordPress theme. It hooks into standard WordPress APIs and does not override theme templates.

= Will it slow down my site? =

Absolutely not. In fact, the performance caching layer typically reduces page load times by 20–40% on average sites.

= How do I report a bug? =

Please open a support ticket on the WordPress.org plugin support forum or file an issue on GitHub.
